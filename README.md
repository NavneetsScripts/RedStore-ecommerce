# 🛒 RedStore – Responsive eCommerce Website

A modern, fully responsive eCommerce front-end template built with HTML and CSS. Inspired by the RedStore UI and designed for portfolios or small businesses seeking a stylish online presence.

- Responsive design for desktop, tablet, and mobile
- Product showcase grid and promo banners
- Clean custom CSS and easy-to-edit structure
